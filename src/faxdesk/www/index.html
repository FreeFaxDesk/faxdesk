Help

Send: name and fax number (the book fills the number), subject, note, drop the PDF, Send. It queues; the desk sends it within a minute and the row turns sent or failed with the reason. Resend tries again.

Incoming: new faxes appear within a few minutes. Open shows the PDF (print from there). Assign to a person; Done marks it handled by you; click +why afterwards if you want to record what was done (Junk offers to block the sender); Spam hides a sender; Always to routes every future fax from that number to someone; name puts a name on a number.

Sent log: everything sent or failed; Confirmation prints a one-page proof.

Settings: Phone.com token, account, extension; people; how long to keep files. Nothing leaves this PC except the calls to Phone.com.
