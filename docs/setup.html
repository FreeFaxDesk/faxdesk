Get your Phone.com API key

Free Fax Desk talks to your Phone.com fax line through the Phone.com API. That needs three things from your Phone.com account: an API token, your account ID, and the extension your fax number belongs to. Ten minutes, once, on the PC that will run FaxDesk. You need the login of a Phone.com administrator user.

1. Create a permanent API token

  1. Open Phone.com's Access Token page and click the API Client tool link there.
  2. Before you sign in, tick Create permanent token. A permanent token does not expire, so FaxDesk keeps working; a normal token stops after a few hours.
  3. Sign in with your Phone.com administrator login and approve the access.
  4. Copy the token it shows. Treat it like a password: it is shown once, and anyone holding it can send faxes as you.

If the API Client tool refuses your login, ask Phone.com support to enable API access on the account (they are quick about it). If you are not yet a customer, phone.com sells a fax number on every plan.

2. Paste it into FaxDesk

  1. Start FaxDesk and open Settings (the gear).
  2. Paste the token into API token. FaxDesk seals it to your Windows account on this PC; it is never shown again and never leaves the PC except in the calls to Phone.com.
  3. Click Test connection. FaxDesk lists the accounts the token can see, with their IDs.

3. Account ID and extension

  1. Account ID (Phone.com calls it the voip id): copy the number from the Test connection result into the Account box. Most offices have exactly one.
  2. Extension: in the Phone.com console, open Users (or Extensions) and note the extension number of the user your fax number is assigned to. Type it into Extension.
  3. Fax number: your fax line in the form 5551234567. FaxDesk only pulls faxes sent to this number, so other lines on the same account stay out of the inbox.
  4. Click Save, then Test connection again. Green means done. Send yourself a one-page test fax to be sure.

If something is off

  • "could not reach Phone.com": the PC has no internet, or a firewall blocks api.phone.com.
  • Token rejected: it was not created as permanent, or it was pasted with a space. Make a new one.
  • Sends fail with an extension error: the extension does not own the fax number. Check Users in the Phone.com console.
  • Inbox empty but faxes arrive by email: the fax number in Settings does not match the line, digit for digit.
